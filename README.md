## 怎么安装

1️⃣ 打开 Visual Studio Code 的插件栏。 **查看** → **扩展**

2️⃣ 搜索 **Material Design Theme**

3️⃣ 点击 **安装**

4️⃣ **文件** > **首选项** > **颜色主题** > **Material Design Theme**
